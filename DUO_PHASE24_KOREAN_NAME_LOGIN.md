# Duo Phase 24: Korean legal-name login

The driver's **Korean legal name is the visible login ID**. The UI requests only name and password (plus signup consent where applicable); a separate English username is not introduced. Duo is not accessible until admin approval and a valid license. Dual use requires a second approval.

Database update applied to `quickdispatch`: `duo_private.members.login_name` is generated by trimming `real_name` and indexed for lookup. It is **not unique** because drivers may share the same name. An internal UUID is required for identity and access checks.

Android Phase 24 source package: `Duo_Phase24_KoreanLogin.zip`; name validation tests passed. The form is not yet connected to real password authentication.

**Do not treat name-only lookup as proof of identity.** A server-only authentication mechanism must securely verify the password, rate-limit attempts, handle duplicate names and account recovery, and return a cryptographically verified session linked to the internal identity. Never resolve to the first matching Korean name, and never accept a claimed admin ID from the browser as authority.

Keep the developer-only Duo admin page locked until secure backend administration is complete. Do not merge to main prematurely.
